# Public source release

This distribution contains the Research OS 2.0.0 source, tests, templates, Codex Skill and user guide. All included project examples are synthetic and use generic identifiers. It excludes development Git history, internal maintenance notes, private project Vaults, meeting materials, generated outputs, credentials and installed dependencies.

Install dependencies with `npm ci`, then run `npm run check`. Follow README.md to link the CLI and install the Skill. For a local synthetic demonstration, run `node scripts/demo-workflow.js`.

Create research Vaults outside this source repository. Runtime commands can include the local file paths and project facts you provide in their output; review generated logs before publishing them.

No Git author identity, remote or commit history is included. New commits and a GitHub repository have their own attribution and privacy settings. This package does not set those settings or choose a license on the publisher’s behalf.
